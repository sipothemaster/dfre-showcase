# Source materials inbox

Put the original HASP materials here, for example:

- brand guideline PDFs
- logos and icons
- colour and typography references
- screenshots or links exported as files
- example reports, presentations, or dashboards
- notes and feedback from HASP

Files in this directory are ignored by Git by default. Do not remove the local
copies until the relevant rules and approved assets have been recorded in the
maintained design documentation.
