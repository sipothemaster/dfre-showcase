# HASP design workspace

Place the original HASP brand and design materials in `source-materials/`.
That folder is ignored by Git so that internal, licensed, or unapproved files
are not accidentally committed to this public repository.

After reviewing the source materials, the maintained design documentation will
live alongside this file:

- `design-brief.md`
- `brand-tokens.md`
- `reference-audit.md`
- `content-guidelines.md`
- `asset-register.md`
- `decision-log.md`

Approved website assets will be copied separately to
`src/assets/brand/hasp/` when they are ready for implementation.

Document status:

- The source material review was completed on 30 September 2026.
- The current documents are an implementation brief, not HASP approval.
- Open brand and attribution questions are listed in `design-brief.md`.
