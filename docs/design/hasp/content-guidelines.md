# HASP explorer content guidelines

Status: draft
Last reviewed: 30 September 2026

## Voice

Use plain, precise, public-facing English. Explain what the map shows before
describing how it was built. Avoid portfolio language, promotional superlatives,
and unexplained analytical terms.

## Interface copy

- Use sentence case for view names, buttons, controls, help, and headings.
- Keep product and section headings short.
- Reserve uppercase for compact sidebar category labels.
- Name metrics with the same wording in controls, legends, area profiles, and
  documentation.
- Put the unit or denominator next to the metric where ambiguity is possible.
- Write actionable empty states, for example `Select a local authority to view
  small-area values`.
- State when an action loads a different geography or time slice.

## About the data structure

Use this order:

1. What this explorer shows.
2. How to use the map.
3. Metrics and units.
4. Geography and representative-postcode method.
5. Data sources and observation period.
6. Update date and version.
7. Known limitations and missingness.
8. Pipeline and quality controls.
9. Related analysis.
10. Citation, funding, acknowledgements, and contact.

## Data claims

- Do not introduce new analytical interpretations in presentation copy.
- Draw definitions from the repository that owns the measure or classification.
- Preserve unresolved and missing categories where the source contract requires
  them.
- Distinguish observed delivery availability from general service availability.
- Distinguish representative-postcode measurements from complete address-level
  coverage.
- Attach a time period or snapshot date to claims that can change.

## Link labels

Use descriptive labels such as `Read the full methodology`, `View data sources`,
or `See the analytical findings`. Avoid repeated generic `Learn more` links.

## Provisional product labels

Use these only until HASP confirms the public naming:

- Product title: `Delivery availability explorer`
- Subtitle: `Area-level indicators across Great Britain`
- Primary view: `Explore map`
- Secondary view: `About the data`
- Methods link: `Read the full methods and pipeline`
